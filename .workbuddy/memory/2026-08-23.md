## 进度条真根因 + file:// 报错消除（15:30）
- **进度条不显示的真根因**：`.fill` 是 `<span>`，默认 `display: inline`，**inline 元素上的 width/height 无效** → 之前所有方案（内联宽度/rAF/CSS 动画）宽度恒为 0。修复：`.skill-bar .fill` 加 `display: block`，并移除 `width: 0` 基础值（改为动画 from 提供起点，内联 width 直接生效，动画失败也兜底显示）。
- **file:// 锚点警告消除**：`a[href^="#"]` 由 JS 接管（scrollIntoView 平滑滚动 + `history.replaceState` 更新 hash；`href="#"` 占位链接直接 preventDefault），消除 Edge "Unsafe attempt to load URL file://" 警告；`section[id]` 加 `scroll-margin-top: calc(var(--nav-height)+8px)` 防导航遮挡。
- **懒加载干预警告**：证书图片移除 `loading="lazy"`（Edge 节能模式会干预并延迟加载）。
- 提醒：file:// 下部分控制台提示属浏览器固有行为，正式部署（http/https）后自然消失；本地预览建议用 `http://127.0.0.1:8123`。
